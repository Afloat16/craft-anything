# Keep PyInstaller CArchive members inside the payload

## Problem
CArchive member offsets were checked against the whole executable when reading. A malformed table could therefore expose the archive table, cookie or bytes appended by signing as member contents, and an out-of-range PYZ could supply a fabricated nested listing.

## Change
Require each stored member range to end before the CArchive table. Keep the outer listing and valid members, mark invalid ranges unreadable, and explain the limitation. Empty runtime options at the payload boundary remain valid.

## Validation
Added regressions for both cookie formats, crossing the payload boundary, table/cookie/signed-tail offsets, empty options and a valid PYZ placed in the signed tail. Remote validation is pending on the exact commit; no local execution is claimed for this revision.

Roadmap: R3.12.
