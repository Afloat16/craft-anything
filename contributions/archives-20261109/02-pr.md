# Reject ASAR manifest nodes with invalid file metadata

## Problem
ASAR JSON nodes with the wrong shape or missing file metadata were silently treated as empty files, and a non-object files map was accepted as an empty archive. That produces a plausible but incorrect inventory of damaged manifests.

## Change
Validate directory maps, node objects, link values, unsigned file sizes, packed offsets and unpacked markers. Keep valid empty files, numeric offsets, links and unpacked files supported, while retaining existing name and listing limits.

## Validation
Added malformed-manifest fixtures and valid controls. The exact remote revision is awaiting fork CI; no local execution is claimed.

Roadmap: R3.12.
