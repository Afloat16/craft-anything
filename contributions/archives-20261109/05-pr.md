# Extract ZIP entries compressed with bzip2 or XZ

Source: [4cac36386e426e332bd89cb2cfa63894f3a367a5](https://github.com/Afloat16/craft-anything/commit/4cac36386e426e332bd89cb2cfa63894f3a367a5)

Upstream PR: [#1374](https://github.com/storytold/craft-anything/pull/1374)

## Problem
The ZIP directory recognized bzip2 (12) and XZ (95), but extraction rejected both even though the formats crate already includes pure-Rust decoders for these streams.

## Change
Route both ZIP methods through the existing decompressors, preserving TooLarge errors, decoded-size validation and CRC checks. This adds no dependency and keeps encrypted entries unsupported.

## Validation
