# Keep GNU sparse tar payloads out of regular-file extraction

Source: [daaeb4fe6c2db3f805fb9b02f9fbdfe55d80eb4a](https://github.com/Afloat16/craft-anything/commit/daaeb4fe6c2db3f805fb9b02f9fbdfe55d80eb4a)

Upstream PR: [#1382](https://github.com/storytold/craft-anything/pull/1382)

## Problem
GNU PAX sparse archives store extents (and, in version 1.0, a sparse map) instead of the full logical file. The tar walker ignored the sparse metadata and listed these bytes as an ordinary file, allowing extraction of incorrect contents.

## Change
Recognize GNU.sparse metadata, retain GNU.sparse.name when present, and mark the member unsupported with an explicit reconstruction warning. Carry this state across extension headers and clear it after the member, so following ordinary files remain readable.

## Validation
